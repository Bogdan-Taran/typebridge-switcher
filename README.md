# TypeBridge

**Пишите свободно — утилита поможет исправить раскладку.**

`ghbdtn → привет` · `руддщ → hello`

Русский ↔ English · macOS · Apple Silicon

</div>

TypeBridge — небольшая утилита для строки меню macOS. Она отслеживает ввод в поддерживаемых текстовых полях и пытается определить, что слово набрано в неправильной раскладке. При уверенном распознавании утилита исправляет слово и переключает системный язык ввода.

> **Статус проекта:** ранняя версия. Распознавание основано на словаре и эвристиках, поэтому ошибки и пропуски возможны. В этой версии нет отдельных правил вида `зрз = php`.

## Возможности

- Переключение между выбранными русской и английской раскладками.
- Распознавание некоторых слов во время набора или при вводе разделителя.
- Три уровня чувствительности, собственный словарь и исключения.
- Ручное исправление текущего слова и отмена автозамены.
- Работа через строку меню и возможность включить автозапуск.
- Локальная обработка: утилита не сохраняет журнал ввода и не использует буфер обмена.

## Требования

- macOS 13 или новее.
- Mac с Apple Silicon. Скрипт сборки создаёт приложение для `arm64`.
- Xcode или Xcode Command Line Tools со Swift и SDK macOS.
- Добавленные в настройках macOS русская и английская раскладки.

Для установки инструментов командной строки выполните:

```bash
xcode-select --install
```

## Сборка

Откройте Терминал в папке проекта и выполните:

```bash
bash build.sh
```

Готовое приложение появится в `dist/TypeBridge.app`. Скрипт компилирует Swift-код и подписывает приложение локальной ad hoc-подписью. Подпись не является подписью Apple Developer ID, а приложение не заверено Apple; macOS может показать предупреждение при открытии.

Чтобы выбрать другую папку для результата, передайте её скрипту:

```bash
bash build.sh /путь/к/папке
```

Запустить собранное приложение можно двойным нажатием в Finder или командой:

```bash
open dist/TypeBridge.app
```

## Первый запуск

1. Откройте TypeBridge. Его значок **EN ⇄ RU** появится в строке меню; окно настроек можно открыть через этот значок.
2. Для работы в других приложениях предоставьте TypeBridge доступ в разделе **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. Разрешение позволяет утилите определять положение курсора и управлять вводом.
3. Выберите в настройках TypeBridge используемые раскладки для **EN** и **RU**. Если нужной раскладки нет в списке, добавьте её в настройках клавиатуры macOS и обновите список кнопкой **↻**.
4. Убедитесь, что включено **«Автоматически исправлять раскладку»**, и нажмите **«Сохранить настройки»**.
5. В новом документе TextEdit выберите английскую раскладку и наберите `ghbdtn`: утилита попытается преобразовать слово в `привет`.

После пересборки или перемещения приложения macOS может потребовать повторно предоставить разрешение. При необходимости может также потребоваться разрешение **«Мониторинг ввода»**.

## Настройки

### Чувствительность

| Режим | Поведение |
| --- | --- |
| Осторожно | Проверяет слово при вводе разделителя, например пробела. |
| Сбалансированно | Может переключить раскладку начиная с третьего символа, если сочетание достаточно убедительно. |
| Быстро | Может переключить начиная со второго символа для отдельных сочетаний. |

Не каждое слово можно надёжно определить по двум или трём буквам. Быстрый режим реагирует раньше, но может чаще ошибаться.

### Исключения и словарь

- **Не исправлять эти слова** — перечислите слова через пробел или запятую. Можно добавить имена, сокращения и названия, которые не следует менять.
- **Мои слова** — добавьте правильные русские или английские слова через пробел или запятую. Они дополняют словарь распознавания; это не правила текстовой замены.
- **Исключённые приложения** — укажите идентификаторы приложений, по одному на строку. Терминал, iTerm2, VS Code, Xcode и некоторые менеджеры паролей исключены по умолчанию. Также в меню есть пункт **«Исключить текущее приложение»**.

Нажмите **«Сохранить настройки»** после изменений.

### Автозапуск

Включите **«Запускать при входе в macOS»** в настройках TypeBridge. При необходимости проверьте его в разделе **Системные настройки → Основные → Объекты входа и расширения**. Утилита регистрирует автозапуск при первом запуске; его также можно выключить в настройках приложения или macOS.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| **⌥ Option + пробел** | Преобразовать текущее отслеживаемое слово и переключить раскладку. |
| **Esc** | Отменить автоматическое исправление текущего слова до ввода разделителя. |

Ручное исправление и отмена зависят от того, доступно ли поле ввода для проверки положения курсора и текста.

## Если переключение не работает

1. Проверьте, что TypeBridge запущен, автопереключение включено, а в настройках выбраны именно текущие раскладки.
2. Проверьте разрешения **«Универсальный доступ»** и, если необходимо, **«Мониторинг ввода»**. После изменения разрешений или пересборки может потребоваться перезапустить приложение.
3. Проверьте, не добавлено ли приложение или слово в исключения, и попробуйте ввод в новом документе TextEdit.
4. Если одновременно запущен другой переключатель раскладки, временно приостановите его и повторите проверку.

Некоторые приложения и системные поля могут не предоставлять данные о курсоре или тексте через интерфейс доступности macOS. В таких полях исправление может не работать. Защищённые поля ввода пропускаются.

> **Известная проблема:** во время разработки на одном Mac дважды наблюдалась потеря управления после удаления разрешения TypeBridge в «Универсальном доступе». Причина не установлена; откат к этой версии не подтверждает, что проблема устранена. Если необходимо изменить это разрешение, сначала завершите TypeBridge через его меню. При повторном зависании может потребоваться принудительно выключить Mac; несохранённые данные могут быть потеряны.

## Проверка проекта

```bash
bash test.sh
```

Скрипт проверяет преобразование раскладок, распознавание слов, исключения и режимы чувствительности. Эти тесты не заменяют проверку глобального ввода, разрешений и работы в конкретных приложениях.

## Структура проекта

```text
Sources/       приложение, настройки, обработка клавиатуры и распознавание
Tests/         проверки алгоритма распознавания
Resources/     настройки пакета приложения
build.sh       сборка TypeBridge.app
test.sh        запуск проверок
```

Временные файлы сборки находятся в `.build-cache/`, готовое приложение по умолчанию — в `dist/`. Обе папки исключены из Git через `.gitignore`.
